# Photos and logo

Put real photos and the logo file here, then name them in `../content.js`:

- a photo: set `src` on its entry in `photos`, e.g. `hero: { src: 'van-outside-job.jpg', ... }`
- the logo: set `business.logo`, e.g. `logo: 'logo.svg'`

`node website/build.js` lists every photo still needed, with the shot each one should be.
The placeholder images on the sample site say the same thing.

Use the largest originals available — not the copies WhatsApp or Facebook shrank. Only
publish photos taken inside a customer's home with their permission.
